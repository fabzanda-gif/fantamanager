# FantaManager

Prototipo personale di gestionale calcistico costruito con Next.js.

**North Star:** Peschi giocatori. Costruisci una squadra. Gestisci persone.

## Fase attuale
Prima vertical slice UI: Home/Hub. I dati mostrati sono dimostrativi e servono a fissare la direzione visiva prima del collegamento allo stato di gioco e a Supabase.

## Architettura prevista
- Next.js + TypeScript
- Vercel
- Supabase condiviso con la piattaforma dati Serie A
- Stato del gioco isolato in future tabelle `game_*`

Nessuna modifica al database è necessaria per questa prima UI.
